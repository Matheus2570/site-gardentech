# Download do TechVaso pelo site

O APK já está em:

```text
public/TechVaso.apk
```

O site possui uma seção **Aplicativo** com botão de download e compartilhamento.

Depois de publicar o site, o APK poderá ser acessado diretamente em:

```text
https://SEU-SITE/TechVaso.apk
```

## Atualizar o GitHub

Substitua/adicione os arquivos desta versão no seu repositório e rode:

```bash
git add .
git commit -m "Adiciona download do aplicativo TechVaso"
git push
```

Se a Vercel estiver conectada ao GitHub, ela fará um novo deploy automaticamente.
